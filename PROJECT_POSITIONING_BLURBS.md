## 3. Five-Line Project Intro

Bastion is a defensive network engine built for hands-on operators.
It combines local traffic visibility with active control paths.
Current workflows include discovery, targeted scanning, telemetry, and policy preview.
Mitigation actions are exposed through a service-managed daemon and CLI.
Advanced wireless operations are available on supported hardware with elevated privileges.

## 4. Non-Technical 15-Second Version

Bastion is a network watchdog and control tool. It shows what is happening on a local network and lets operators act quickly when something looks wrong.

## 5. Technical 45-Second Version

Bastion is a Rust-based network defense platform with a daemon + CLI architecture and local IPC control surface. It supports discovery and targeted scanning workflows, policy recommendation preview, live telemetry, and active mitigation commands. The runtime is designed for transparent operator control with auditable outputs and scripted operational paths. Advanced wireless operations are hardware-dependent and require elevated privileges.
